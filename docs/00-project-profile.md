## 2. Elevator Pitch

> ใน 2–3 ประโยค อธิบายว่า “ระบบนี้ช่วยใคร แก้ปัญหาอะไร และสร้างคุณค่าอย่างไร”

[เว็บไซต์นี้ช่วยแก้ปัญหาความยุ่งยากในการจัดคิวและเข้าถึงทรัพยากรทางการศึกษา โดยช่วยให้นักศึกษาและบุคลากร สามารถค้นหา ตรวจสอบสถานะว่าง และจองห้องนั่งทำงาน (Space) รวมถึงอุปกรณ์การเรียนรู้ต่างๆ ได้แบบ Real-time บนหน้าเว็บ ซึ่งช่วยลดความซ้ำซ้อนในการจอง และเพิ่มประสิทธิภาพในการใช้พื้นที่ของมหาวิทยาลัยให้คุ้มค่าที่สุด]

## 3. Scope ระดับสูง

### In Scope
- ระบบสมัครสมาชิกและเข้าสู่ระบบ
- ระบบจองห้องและอุปกรณ์
- ตรวจสอบตารางการจอง 
- ยกเลิกการจอง
- จัดการข้อมูลห้องและอุปกรณ์
- รายงานการใช้งาน

### Out of Scope
- ระบบชำระเงิน 
- การซ่อมบำรุงอุปกรณ์
- การเชื่อมต่อกับระบบสารสนเทศของมหาวิทยาลัย
- ระบบควบคุมการเปิด–ปิดห้องอัตโนมัติ

## 4. ผู้ใช้หลัก

| Role | เป้าหมายหลัก | สิ่งที่คาดว่าจะทำกับระบบเว็บไซต์ |
|---|---|---|
| นักศึกษา / บุคลากร | ค้นหา จอง รับ และคืนทรัพยากร/พื้นที่ทำงานได้อย่างรวดเร็ว | ค้นหาห้อง/อุปกรณ์ ตรวจสอบตารางเวลาว่าง ส่งคำขอจอง และกดยกเลิกการจองผ่านหน้าเว็บ |
| อาจารย์ | จองห้องและอุปกรณ์สำหรับการเรียนการสอนหรือกิจกรรมพิเศษ | ส่งคำขอจองพื้นที่หรืออุปกรณ์ล่วงหน้า และตรวจสอบสถานะการอนุมัติ |
| เจ้าหน้าที่ห้อง | ตรวจสอบสถานะของห้องและทรัพยากรได้ง่าย ลดภาระงานเอกสาร และติดตามอุปกรณ์ได้ถูกต้อง | ตรวจสอบและกดอนุมัติ/ปฏิเสธคำขอจองห้อง บันทึกการส่งมอบ-รับคืนอุปกรณ์ และติดตามรายการส่งคืนล่าช้า |
| ผู้ดูแลระบบ | ดูแลข้อมูลและสิทธิ์ผู้ใช้งาน รักษาความปลอดภัยของระบบ | จัดการบัญชีผู้ใช้ กำหนดสิทธิ์ และตรวจสอบ Audit Log ประวัติการทำรายการ |
| ผู้บริหารสถานศึกษา | ติดตามการใช้ทรัพยากรและวางแผนการจัดสรรงบประมาณ | ดูรายงานสถิติอัตราการใช้พื้นที่ อัตราการยืมอุปกรณ์ และสถิติ No-show บนหน้า Dashboard |

## 5. Success Criteria ระดับสูง

- **[SC-01]** ผู้ใช้สามารถทำรายการจองพื้นที่หรืออุปกรณ์เสร็จสิ้นบนหน้าเว็บไซต์ภายในเวลาไม่เกิน 3 นาที
- **[SC-02]** ระบบบนหน้าเว็บสามารถป้องกันการจองซ้ำซ้อน (Double Booking) ในช่วงเวลาเดียวกันได้อย่างถูกต้อง 100%
- **[SC-03]** เจ้าหน้าที่สามารถดึงรายงานประวัติการใช้งานประจำเดือนออกมาจากหน้าเว็บเพื่อนำไปวิเคราะห์การจัดสรรพื้นที่ได้
