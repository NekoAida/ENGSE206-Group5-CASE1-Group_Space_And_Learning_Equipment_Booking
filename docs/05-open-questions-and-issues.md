## 2. Issues / Holds

| Issue ID | เรื่องที่ต้อง Hold | เหตุผล | สิ่งที่ต้องเก็บเพิ่ม |
|---|---|---|---|
| ISSUE-GSEB-01 | ข้อยกเว้นการจองห้องเกินโควตาเวลา | ยังไม่มีหลักฐานแน่ชัดว่าต้องมีระบบยื่นขออนุมัติกรณีพิเศษสำหรับวิชาโครงงานหรือไม่ | นโยบายการใช้ห้องพิเศษจากคณะ/ผู้จัดการพื้นที่ |
| ISSUE-GSEB-02 | ลำดับสิทธิ์กรณีอุปกรณ์ชิ้นสุดท้าย | ยังไม่มีข้อสรุปชัดเจนหากมีผู้ส่งคำขอจองอุปกรณ์ชิ้นสุดท้ายเข้ามาพร้อมกันในเวลาเดียวกัน | เกณฑ์ตัดสินใจจากเจ้าหน้าที่ + System Concurrency Test |
| ISSUE-GSEB-03 | การอุทธรณ์การระงับสิทธิ์ No-show | ยังไม่มีแนวทางการรับเรื่องอุทธรณ์หากนักศึกษามีเหตุจำเป็นสุดวิสัย (เช่น อุบัติเหตุ/ป่วย) | กระบวนการอุทธรณ์จากผู้จัดการพื้นที่และเจ้าหน้าที่ |
| ISSUE-GSEB-04 | ช่องทางและเวลาในการแจ้งเตือน | ยังไม่ได้ยืนยันว่าผู้ใช้ต้องการ Email แจ้งเตือนทันทีทุกรายการ หรือสรุปรายวัน | แบบสอบถาม/สัมภาษณ์นักศึกษาเกี่ยวกับความถี่ Notification |
| ISSUE-GSEB-05 | รายงานสรุปสำหรับผู้บริหาร | ยังไม่ทราบตัวชี้วัดที่แน่นอนว่าผู้บริหารเน้นสถิติการใช้ห้องหรืออัตราการยืมอุปกรณ์มากกว่ากัน | ตัวอย่างรายงานสรุปประจำเดือนหรือ KPI จากผู้บริหาร |
| ISSUE-GSEB-06 | มาตรการควบคุมการคืนอุปกรณ์ล่าช้า | ยังไม่มีนโยบายแน่ชัดเรื่องค่าปรับหรือการระงับสิทธิ์กรณีส่งคืนอุปกรณ์สาย | ข้อระเบียบการยืม-คืนครุภัณฑ์ของคณะ/สถาบัน |
