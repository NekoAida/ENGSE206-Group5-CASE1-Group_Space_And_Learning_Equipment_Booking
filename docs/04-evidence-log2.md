## 4. New / Revised Insights

- ระบบไม่ควรมองการจองพื้นที่และการยืมอุปกรณ์เป็นกระบวนการเดียวกัน เนื่องจากอุปกรณ์ต้องการความรวดเร็ว (Auto-approve) ขณะที่ห้องต้องอาศัยการจัดสรรความเหมาะสม (Manual Approve)
- เงื่อนไขการเช็กอินภายใน 15 นาทีมีความสำคัญมากในการลดปัญหา "ห้องถูกจองแต่ไม่มีคนใช้" (Ghost Booking)
- การจำกัดสิทธิ์จองล่วงหน้าไม่เกิน 7 วัน และใช้งานไม่เกิน 3 ชั่วโมง/วัน ช่วยกระจายการเข้าถึงทรัพยากรได้อย่างเป็นธรรม
- จำเป็นต้องมีระบบ Audit Log และฟิลด์บันทึก Asset ID หน้าเคาน์เตอร์ เพื่อใช้ตรวจสอบย้อนหลังกรณีอุปกรณ์ชำรุดหรือสูญหาย
