# 03 — Interview Guide and Rehearsal Revision

> Team: Group 5 | Case: 01 — Group Space And Learning Equipment Booking System | Target role: เจ้าหน้าที่ดูแล (Staff / Admin)

## 1. Opening and Consent Script

สวัสดีครับ พวกเราเป็นนักศึกษาจากรายวิชา ENGSE206 กำลังรวบรวมข้อมูลเพื่อพัฒนาระบบจองพื้นที่ทำงานกลุ่มและอุปกรณ์การเรียนรู้ การสัมภาษณ์นี้ใช้เวลาประมาณ 15-20 นาที ข้อมูลทั้งหมดจะถูกนำไปใช้เพื่อการเรียนรู้และออกแบบระบบเท่านั้น จะไม่มีการเปิดเผยข้อมูลส่วนบุคคลหรือข้อมูลที่เป็นความลับ ท่านสามารถปฏิเสธที่จะตอบคำถามหรือยุติการสัมภาษณ์ได้ตลอดเวลา

## 2. Interview Questions

| Q ID | EO ID | Main / Follow-up Question | Type | Why / Expected Evidence |
|---|---|---|---|---|
| Q-01 | EO-01 | ปัจจุบันมีการจำกัดจำนวนวันในการจองล่วงหน้าหรือไม่ และในระบบใหม่ควรให้จองล่วงหน้าได้สูงสุดกี่วัน เพราะเหตุใด | Open / Probe | เพื่อหาข้อกำหนดเรื่องเวลาการจองล่วงหน้าที่เหมาะสมกับผู้ดูแลและผู้ใช้ (จาก OQ-01) |
| Q-02 | EO-01 | ปกติแล้วนักศึกษาใช้งานห้องทำงานกลุ่มแต่ละครั้งนานเท่าใด ควรจำกัดจำนวนชั่วโมงสูงสุดต่อการจองไว้ที่เท่าใดเพื่อป้องกันการผูกขาด | Confirm / Probe | เพื่อหาข้อกำหนดโควตาเวลาการใช้งานต่อวันและต่อครั้ง (จาก OQ-01, F-03) |
| Q-03 | EO-01 | การแสดงสถานะห้องและอุปกรณ์ว่างแบบ Real-time บนหน้าเว็บ ควรแสดงข้อมูลและเงื่อนไขใดบ้างเพื่อลดการจองชนกัน | Open / Probe | เพื่อใช้กำหนด UI และ Data Field ในหน้าแสดงตารางว่าง (จาก PP-01, G-01) |
| Q-04 | EO-02 | ในการจองห้องทำงานกลุ่ม เจ้าหน้าที่มีเกณฑ์หรือกระบวนการพิจารณาอนุมัติหรือปฏิเสธคำขออย่างไร และต้องระบุเหตุผลเมื่อปฏิเสธหรือไม่ | Open / Workflow | เพื่อกำหนดฟังก์ชันและสิทธิ์การกด Approve/Reject ของเจ้าหน้าที่ (จาก PP-03) |
| Q-05 | EO-02 | สำหรับอุปกรณ์การเรียนรู้ทั่วไป เช่น สายแปลงสัญญาณ หรือ Webcam เห็นด้วยหรือไม่หากระบบจะอนุมัติการจองแบบอัตโนมัติ (Auto-approve) และมีอุปกรณ์ใดที่ต้องรออนุมัติพิเศษ | Open / Rule | เพื่อนำไปออกแบบตรรกะการอนุมัติการยืมอุปกรณ์และลดภาระงานเจ้าหน้าที่ (จาก PP-03) |
| Q-06 | EO-03 | ในกรณีที่นักศึกษาจองไว้แต่ไม่มาเช็กอินใช้งานจริง (No-show) ควรให้ระบบยกเลิกคำขอจองอัตโนมัติ (Auto-cancel) หลังผ่านไปกี่นาที | Open / Probe | เพื่อกำหนดตัวเลขเวลาและเงื่อนไขการตัดสิทธิ์ No-show (จาก OQ-02) |
| Q-07 | EO-03 | หากนักศึกษาเกิด No-show หรือคืนอุปกรณ์ล่าช้า ควรมีมาตรการตักเตือนหรือระงับสิทธิ์ชั่วคราวอย่างไร และควรแจ้งเตือนผ่านช่องทางใด (Web / Email) | Open / Rule | เพื่อกำหนดนโยบายการลงโทษและการส่งข้อความแจ้งเตือนสถานะคำขอ (จาก C-03, C-04) |
| Q-08 | EO-04 | ในขั้นตอนการส่งมอบและรับคืนอุปกรณ์ เจ้าหน้าที่จำเป็นต้องบันทึกรหัสครุภัณฑ์ (Asset ID) และตรวจสภาพอุปกรณ์อย่างไรบ้าง | Open / Inventory | เพื่อออกแบบฟอร์มบันทึกการรับ-คืน และการตัดสต็อกอุปกรณ์ (จาก F-01, A-02) |
| Q-09 | EO-04 | เพื่อความโปร่งใสและความปลอดภัย ระบบควรจัดเก็บประวัติการทำรายการ (Audit Log) ในส่วนใดบ้าง และใครควรมีสิทธิ์เข้าถึงหรือตรวจสอบย้อนหลังได้ | Open / Security | เพื่อนำไปกำหนดข้อกำหนด Non-functional และตาราง Audit Log (จาก G-03, NFR) |
| Q-10 | EO-04 | ผู้บริหารหรือผู้จัดการพื้นที่ต้องการดูรายงานสรุปหรือสถิติประเภทใดบ้างบนหน้า Dashboard เพื่อใช้วางแผนจัดสรรทรัพยากร | Open / Reporting | เพื่อกำหนดฟิลด์ข้อมูล กราฟ และตัวชี้วัดสำหรับการแสดงผล Dashboard (จาก G-03) |

| Q-01 | Vague | ท่านคิดว่าระยะเวลาที่เหมาะสมในการอนุญาตให้นักศึกษาจองล่วงหน้าคือเท่าใด และควรจำกัดเวลาใช้งานต่อครั้งหรือไม่ | เปลี่ยนคำถามให้เจาะจงที่ความคิดเห็นของเจ้าหน้าที่โดยตรง |

## 4. AI Interview Rehearsal

- Role/prompt used: "สวมบทบาทเป็นเจ้าหน้าที่ดูแลระบบจองห้องและอุปกรณ์การเรียนรู้ (Media Officer) ตอบคำถามสัมภาษณ์เพื่อพัฒนาระบบจองผ่านเว็บไซต์ โดยอ้างอิงจากปัญหาปัจจุบันคือ มีการจองซ้ำซ้อน และห้องว่างแต่ไม่มีคนมาใช้งานจริง เนื่องจากทรัพยากรมีจำกัด"
- Session/evidence path: จำลองการสัมภาษณ์ผ่าน AI (Week 03 Rehearsal)
- Simulation limitation: AI อาจให้คำตอบที่เป็นอุดมคติเกินไปและไม่ได้สะท้อนข้อจำกัดเชิงกายภาพและพฤติกรรมจริงในสถานที่จริง

| Q ID | What happened | Useful probe / problem | Revised question |
|---|---|---|---|
| Q-01 | AI ตอบว่าควรจองล่วงหน้าได้ไม่เกิน 7 วัน และจำกัด 2-3 ชม./กลุ่ม เพื่อลดการผูกขาด | AI ตอบกว้างไป ควรเจาะจงว่าถ้าไม่มีคนรอคิว สามารถขยายเวลาในระบบได้หรือไม่ | ปัจจุบันมีการจำกัดจำนวนวันในการจองล่วงหน้าหรือไม่ ในระบบใหม่ควรให้จองล่วงหน้าได้สูงสุดกี่วัน และหากไม่มีคิวจองต่อควรอนุญาตให้ต่อเวลาได้หรือไม่? |
| Q-05 | AI ตอบว่าอุปกรณ์ควร Auto-approve ได้ทั้งหมด | AI ไม่ได้คำนึงว่าอุปกรณ์บางชิ้นมีราคาสูงและต้องตรวจสอบสิทธิ์ | แยกประเภทอุปกรณ์ทั่วไป (Auto-approve) ออกจากอุปกรณ์เฉพาะทางที่ต้องรออนุมัติ |
| Q-06 | AI เสนอว่าถ้านักศึกษาไม่มาภายใน 15 นาที ให้ระบบยกเลิกอัตโนมัติทันที | ไม่ได้คำนึงถึงกรณีนิสิตมาสายเพราะเหตุสุดวิสัย | ในกรณีที่นักศึกษาจองไว้แต่ไม่มาเช็กอินภายในเวลาที่กำหนด (เช่น 15 นาที) ระบบควรยกเลิกอัตโนมัติหรือไม่ และควรมีช่องทางผ่อนผันหากมาสายจากเหตุสุดวิสัยอย่างไร? |
